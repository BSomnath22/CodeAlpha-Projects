# 📈 Stock Portfolio Tracker in Python

A simple command-line **Stock Portfolio Tracker** built using Python. This program allows users to add stocks, enter quantities, calculate total investment value, and save the portfolio details into a text file.

## ✨ Features

* User input for stock names and quantity
* Hardcoded stock price dictionary
* Automatic investment calculation
* Portfolio summary display
* Input validation for stock names and quantities
* Saves portfolio details into a **portfolio.txt** file

## 🛠️ Technologies Used

* Python 3

## 📂 Project Structure

```text
stock_portfolio_tracker.py
portfolio.txt
README.md
```

## 🎯 How It Works

* The program displays available stocks.
* User enters the number of stocks to add.
* User inputs stock name and quantity.
* The program validates stock names and quantity.
* Total investment value is calculated automatically.
* Portfolio details are saved in a **portfolio.txt** file.

## ▶️ How to Run

1. Install Python 3 on your system.
2. Download or clone this repository.
3. Open terminal or command prompt.
4. Run the program using:

```bash
python stock_portfolio_tracker.py
```

## 📁 Output File

The program automatically generates a file named:

```text
portfolio.txt
```

This file contains:

* Stock details
* Quantity purchased
* Individual investment values
* Total investment value
