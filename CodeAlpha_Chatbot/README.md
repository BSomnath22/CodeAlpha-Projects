# CodeAlpha_BasicChatbot

# 🤖 Basic Chatbot in Python

A simple command-line **Rule-Based Chatbot** built using Python. This chatbot interacts with users using predefined responses, handles greetings, answers common questions, tells jokes, and responds to different user inputs.

## ✨ Features

* Interactive chatbot conversation
* Rule-based responses using **if-elif conditions**
* Handles greetings and common questions
* Personalized conversation flow
* Joke-telling feature
* Input validation for better interaction
* Loop-based conversation system
* Exit option using **"bye"**

## 🛠️ Technologies Used

* Python 3

## 📂 Project Structure

```text
basic_chatbot.py
README.md
```

## 🎯 How It Works

* The chatbot starts and waits for user input.
* Users can greet the bot using words like **hello** or **hi**.
* The chatbot responds with predefined answers.
* It can answer common questions such as:

  * Who are you?
  * What is your name?
  * Tell me a joke
  * How are you?
  * Do you like Python?
* The chatbot continues running in a loop until the user types **bye**.
